# Security

This project is under active development and has not received an independent security audit. Do not include credentials, private manuscripts or personal information in public issues.

For a vulnerability, use GitHub's private vulnerability reporting feature if enabled on this repository. If it is unavailable, open a minimal public issue asking for a private reporting channel, without technical exploit details or sensitive data. No dedicated security email or response-time guarantee is currently offered.

Keep PostgreSQL, Mailpit, backups and AI credentials private. Disable public signup until outbound email is configured. Do not enable live AI without explicit budget and data-transfer review. See docs/THESIS_WORKFLOW.md for current limitations.
